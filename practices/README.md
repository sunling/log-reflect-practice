# Practices

Practice 是从记录中长出来、愿意持续尝试并接收反馈的行动，不是另一种资料分类。

## 什么时候创建

至少出现以下一种证据时，再考虑建立 Practice：

- 同一需要或问题反复出现；
- 已经开始行动，想观察它带来的变化；
- 外部反馈推动你继续做下去。

## 最小结构

```text
practices/<实践名>/
├── mission.md   # 为什么做、服务谁、边界是什么
└── current.md   # 现在正在尝试什么、下一步是什么
```

需要更多文件时再增加，不要提前搭建复杂系统。可以参考 [`examples/practice/`](../examples/practice/)。
