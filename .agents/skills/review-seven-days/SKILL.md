# Review Seven Days

让使用者重新看见自己的材料，不急着替其下结论。

## 步骤

1. 默认回看包含今天在内的最近 7 个自然日；若日期范围不清楚，先说明你采用的范围。
2. 只读取范围内的 `daily/journal/` 与 `daily/inputs/`。除非使用者要求，不扫描全部历史记录。
3. 为每个判断列出具体记录日期或相对链接。
4. 区分四类发现：
   - 重复：多次出现的词、需要、情绪或处境；
   - 变化：语气、判断或行动与较早记录不同；
   - 行动：已经真实发生的尝试；
   - 未完成：仍在等待回应的问题。
5. 先在对话中呈现回看结果。只有使用者确认后，才写入新文件或更新 Practice。

## 输出格式

```markdown
## 本次范围

## 我看到的重复

## 正在发生的变化

## 已经采取的行动

## 仍未完成的问题

## 一个轻量的下一步
```

“一个轻量的下一步”必须来自已有材料，且保持可拒绝、可调整。
