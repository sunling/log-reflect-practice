# Capture Journal

把使用者的经验整理得更容易回看，同时保留其原有语气和不确定性。

## 步骤

1. 从使用者提供的内容中识别日期、事件、感受、身体反应和仍未解决的问题。
2. 缺少日期时询问；若日期对任务不重要，可使用当前日期并明确说明。
3. 不补写未被提及的人物动机、心理解释或行动结果。
4. 起草记录，优先使用第一人称；允许短句、犹豫和空白存在。
5. 保存到：

   ```text
   daily/journal/{YYYY}/{YYYYMM}/{YYYYMMDD}-周X-{关键词}.md
   ```

6. 如果提到相关输入或 Practice，使用相对链接连接；不要为了“完整”而创建不存在的文件。

## 建议结构

```markdown
# 标题

日期：YYYY-MM-DD

## 发生了什么

## 我当时的感受与反应

## 现在还留着什么
```

只保留有材料的部分。完成后告诉使用者文件路径，以及你做了哪些轻微整理。
