# Capture Input

保存真正有用的外部输入，而不是把整篇内容搬进仓库。

## 步骤

1. 识别输入类型、标题、作者或说话者、来源链接和接触日期。
2. 只根据使用者提供的材料或可核验来源写摘要；无法确认的信息标为未知。
3. 明确分开“来源内容”和“我的回应”，不要把两者混写。
4. 摘录只保留理解所需的短片段，并注明来源；不要复制大段受版权保护的内容。
5. 保存到：

   ```text
   daily/inputs/{YYYY}/{YYYYMM}/{YYYYMMDD}-{关键词}.md
   ```

6. 若输入触发了个人经历，可建议另建 journal；不要自动把一次触动升级成 Practice。

## 建议结构

```markdown
# 标题

- 日期：YYYY-MM-DD
- 类型：
- 来源：
- 链接：

## 来源在说什么

## 哪些部分触动了我

## 我由此想到什么

## 可能继续追问
```

删除没有内容的字段。完成后报告文件路径和仍待补充的来源信息。
