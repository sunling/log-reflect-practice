# Capture Inputs / 捕获碎片输入

## 目标

先把真实输入保存下来，不因为分类、提炼或输出压力而丢失当时的触动。

默认写入：

```text
daily/inputs/{YYYY}/{YYYYMM}/{YYYYMMDD}-{关键词}.md
```

`capture-input` 只负责捕获和轻量整理，不负责一次性生成文章、建立复杂项目或替用户得出成熟结论。

知识、智识和智慧可以作为回看一条输入的视角，但不是每条笔记都必须完成的固定栏目：

- 我接触到的内容是什么；
- 它为什么在此刻触动我；
- 它跟我的经历、判断或相信的东西有什么关系；
- 它是否可能影响行动、选择或某个 Practice。

## 什么时候使用

适合：

- “记录一下”；
- “笔记入库”；
- “我刚刚听到一个观点”；
- “把这段播客、阅读或对话感受留下来”；
- 一段语音转文字、临时闪念或生活观察。

不适合：

- 已明确要写完整文章或分享稿：使用对应写作 Skill；
- 已明确要推进某个持续项目或公开输出：进入对应 Practice。

## 存储与命名

```text
daily/inputs/{YYYY}/{YYYYMM}/
```

示例：

```text
daily/inputs/2026/202607/20260712-学习与炼化.md
```

规则：

- 需要确定日期时，优先读取 `PROFILE.md` 中的时区；未填写时使用当前执行环境的本地日期，若相对日期仍有歧义再询问；
- 年月目录不存在时安全创建；
- 文件名只保留日期和关键词，不加入来源、平台或输入类型；
- 关键词概括这条输入未来最值得重新找到的内容，不使用空格、斜杠或无意义的版本词；
- 同日同一输入已有文件时，优先更新原文件，不创建 `v2` 或 `final`；
- 同日出现不同输入但关键词重名时，进一步具体化关键词；
- 不向 `daily/inputs/_legacy/` 写入新内容。

来源不是必填信息。只有原始材料明确提供了书名、节目、平台、作者或对话对象等外部来源时，才在 frontmatter 中增加 `source`。来源不明确时直接省略，不写“其他”，也不要猜测。

## 整理原则

### 1. 始终保留真实输入

每条笔记至少保留：

- 输入是什么；
- 为什么这一刻值得留下；
- 用户的原始表达。

可以清理明显识别错误、断句和无信息噪音，但不要把原始表达改写成成熟文章。

### 2. 有内容时再展开

下面这些部分只有材料真实存在时才出现，不为了模板完整而补空话：

- 必要的来源或概念背景；
- 与当下生活、写作、关系、工作或某个 Practice 的连接；
- 它呼应、挑战或改变了什么判断；
- 仍然不确定的问题；
- 一个可能的行动或 Practice 去向。

不知道时少写，不编造作者、嘉宾、数据、链接、经历、动机和结论。

### 3. 不强迫行动化

一条输入可以只被保存，不必立刻变成待办、文章或 Practice。

只有在用户已经表达真实意愿时，才记录：

- 继续观察的问题；
- 可以尝试的一个小行动；
- 已经准备进入的 Practice。

不要同时维护“后续行动”和“可能的下一步”两套重复栏目。

### 4. 不自动制造下游文件

除非用户明确要求，不自动创建文章、分享稿、项目材料或多个衍生文件。

判断可以是：

- 仍在生活和思考中发生 → 留在 Daily；
- 已准备通过持续行动或公开表达接受真实反馈 → 进入对应 Practice；
- 出现反复使用的 AI 工作流 → 考虑更新或新建 Skill；
- 最有价值的是一次选择、对话或实验 → 直接行动，不继续生成文件。

## Markdown 模板

根据材料使用最小版本或展开版本。

### 最小版本

```md
---
title: "{标题}"
date: {YYYY-MM-DD}
tags:
  - {1–3 个标签}
---

## 输入是什么
{必要的内容、观点或背景}

## 为什么此刻想留下
{用户当下的触动；信息不足时保留原始提问或观察}

---
## 我的原始笔记
> {用户原话}
```

若原始材料明确提供了外部来源，可在 frontmatter 中增加：

```yaml
source: "{明确的书名、节目、平台、作者或其他来源}"
```

### 有真实连接时可增加

```md
## 我的思考与关联
{它跟经历、判断、关系、工作或 Practice 的真实连接}

## 仍在想的问题
- {没有答案也可以保留}

## 可能的行动或去向
- {只写一个真实存在的行动、Practice 或“继续留在 Daily”}
```

不要保留空栏目，也不要用“暂无”填满模板。

## 执行反馈

创建后简要说明：

1. 新文件路径；
2. 这条输入为什么值得留下；
3. 若存在，最重要的一条个人连接或真实行动；
4. 若有必要，说明哪些事实或理解仍未确认。
