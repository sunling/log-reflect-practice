# Explore New Bubble

帮助使用者持续接触“世界本身”，而不只是继续消费熟悉的知识型或自我成长型内容。

```text
发现一个陌生而具体的资源
→ 生成一个阅读、收听或观看任务
→ 使用者真正完成
→ 记录完成事实与真实回应
```

一次只推进一个资源。推荐不等于完成；完成也不等于必须输出心得。

## 发现资源

1. 按需读取最近少量 `daily/inputs/`，了解近期领域和已完成资源。不要为了个性化扫描全部历史。
2. 使用可用的联网工具搜索候选资源，并核实：
   - 标题与作者、机构或节目名称；
   - 链接目前可以访问；
   - 内容是一个能够完成的具体单元；
   - 时长或篇幅只在有可靠信息时给出。
3. 只选择 **1 个**资源。优先满足：
   - 与近期输入在领域、生产者、形式或问题意识上有明显距离；
   - 包含第一手经验、长期观察、调查、纪录或专业实践；
   - 能成为一个陌生领域的具体入口，而不只是提供有趣事实。
4. 先在对话中给出任务，不创建 Daily 文件。
5. 等使用者明确说“完成了”“读完了”“听完了”或“看完了”，再记录完成。

## 探索方向

可以从自然科学、生态、城市、基础设施、制造、农业、普通职业、历史、考古、人类学、艺术、音乐、博物馆、法律或公共制度的具体案例中寻找。

默认降低以下内容的优先级：

- self-help、效率和个人成长；
- 泛心理学和“如何过好人生”式观点；
- 只解读另一份内容的二手总结；
- 与近期推荐高度相似的主题。

语言多样性是加分项，但领域和内容生产方式的多样性更重要。

## 推荐格式

```markdown
## 今日陌生输入

**任务**：认真读完 / 听完 / 看完《标题》

- 来源：作者、机构、刊物、播客或频道
- 类型：文章 / 播客 / 纪录片 / 视频 / 书中一章
- 预计时间：仅在可以核实时填写
- 链接：已经核实的链接

**为什么选它**

用 2—4 句话说明它与近期常见输入哪里不同，以及它打开了哪一扇新窗口。

完成后只需要告诉我：“完成了”。不要求写心得；有想法时再记录。
```

不要附带“顺便还可以看”的链接，不把资源强行翻译成个人成长启示，也不要夸张承诺它会改变使用者。

## 记录完成

1. 从当前对话确认最近一个明确推荐的资源；无法确定时询问，不要猜。
2. 使用 `PROFILE.md` 中的时区记录实际完成日期；未设置时区则询问。
3. 按 `capture-input` 的命名协议写入：

   ```text
   daily/inputs/{YYYY}/{YYYYMM}/{YYYYMMDD}-{关键词}.md
   ```

4. 同一资源已有记录时更新原文件，不创建 `v2` 或 `final`。
5. 默认只记录内容、类型、来源、链接和完成时间。
6. 使用者主动分享感受时，追加“我留下来的东西”，只整理其真实表达，不代写心得。

## 完成记录模板

```markdown
# 资源标题

- 完成时间：YYYY-MM-DD HH:mm
- 类型：
- 来源：
- 链接：
- 发现方式：New Bubble

## 完成记录

我完成了这份内容。这次只记录完成事实，不要求总结。

## 我留下来的东西

仅在使用者主动表达想法时加入这一节。
```

完成后简短报告写入或更新的相对路径。
