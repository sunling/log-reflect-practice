# Doubao + Feishu 环境配置库

本目录（`refs/doubao-feishu/`）包含了为主仓库核心工作流在 **豆包（Doubao）智能体平台** 上运行所专门设计的变体。

此环境下的核心特点是：**系统依赖于飞书云盘（Feishu Drive）插件进行最终的文件持久化存储**。

## 目录结构

- `skills/`：供在豆包 Bot 中创建具体“技能（Skill）”时复制粘贴的 Prompt。所有的写入、读取步骤都已被改写为飞书云盘 API 的执行逻辑。
- `scheduled-task-prompt/`：供豆包创建定时任务、计划任务时参考和复制的系统 Prompt（例如每天早上推送打卡任务、隔天推荐输入源等）。

## 包含的 Skills

目前本目录下包含以下核心功能的适配：

- **`capture-journal`**：用于将口语化、碎片化的语音转录或随手记录，整理为真实自然的个人日记（存入飞书云盘的 `daily/journal/` 目录）。
- **`capture-input`**：用于将文章、播客、视频等外部输入，以及读书闪念等低摩擦地整理归档（存入飞书云盘的 `daily/inputs/` 目录）。
- **`bubble-breaker`**：用于主动推荐并记录与现有 feed 不同的陌生领域高质量资源，打破信息茧房（完成的记录存入飞书云盘的 `daily/inputs/` 目录）。
- **`review-daily-entries`**：用于回看近期（如最近七天）在飞书云盘上的输入和日记，识别反复出现的线索、触动和变化，给出继续行动的方向。
- **`write-weekly-article`**：读取飞书云盘中过去七天的日记和输入，整理成一篇默认给自己看的周记文章。
- **`develop-practice`**：用于将日常记录中反复出现的线索，转化为最小可持续的长期实践（存入飞书云盘的 `practices/` 目录）。


## 使用指南
在使用本目录下的配置时，请确保你的智能体（Bot）：
1. 拥有支持文件操作的**飞书插件**能力。
2. 已经完成了飞书云盘相关的认证授权。
3. 在飞书云盘中准备 `daily/journal/`、`daily/inputs/` 与 `practices/` 的根目录，或允许 Bot 首次使用时创建。
4. 先用一条不敏感的测试记录验证读取、创建与追加都成功，再建立计划任务。
5. 如果发生读写故障，请检查云盘目录的层级建立规则（如按年月划分）。
6. 飞书 Drive 允许同名文件夹并存。任何 Skill 在执行 `create-folder` 前都必须完整列出父目录子项并精确匹配名称：1 个则复用、0 个才创建、多个则停止创建并消歧。
