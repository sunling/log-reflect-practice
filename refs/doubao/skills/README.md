# Doubao Skills 飞书云盘适配版

本目录（`refs/doubao/skills/`）下的所有 Skill 都是为主仓库核心 Skill 的**豆包（Doubao）/飞书生态**适配版本。

由于在豆包/AI 对话环境中，本地文件系统往往是临时的，因此这套 Skill 的最大特点是：**所有的最终记录与输出，都是为了持久化存储到「飞书云盘（Feishu Drive）」而设计的。** 

系统会在生成文档后，通过飞书相关的指令或工具，将 md 文件按照约定的目录结构（如 `daily/inputs/{YYYY}/{YYYYMM}/`）归档到飞书云盘中。

## 包含的 Skills

目前本目录下包含以下核心功能的适配：

- **`capture-journal`**：用于将口语化、碎片化的语音转录或随手记录，整理为真实自然的个人日记（存入飞书云盘的 `daily/journal/` 目录）。
- **`capture-input`**：用于将文章、播客、视频等外部输入，以及读书闪念等低摩擦地整理归档（存入飞书云盘的 `daily/inputs/` 目录）。
- **`bubble-breaker`**：用于主动推荐并记录与现有 feed 不同的陌生领域高质量资源，打破信息茧房（完成的记录存入飞书云盘的 `daily/inputs/` 目录）。
- **`review-daily-entries`**：用于回看近期（如最近七天）在飞书云盘上的输入和日记，识别反复出现的线索、触动和变化，给出继续行动的方向。
- **`develop-practice`**：用于将日常记录中反复出现的线索，转化为最小可持续的长期实践（存入飞书云盘的 `practices/` 目录）。

## 使用注意事项

- 修改或自定义本目录下的 Skill 时，请特别注意保留关于**飞书云盘上传执行**的流程说明。
- 文件命名与目录分层结构（如按年月划分的文件夹）依赖于云盘接口的正确调用逻辑，修改相关逻辑时请确保云盘的文件夹创建机制正常。
