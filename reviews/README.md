# Reviews

这里保存对一段时间 Daily 的回看档案。回看是从原始记录走向问题、表达与 Practice 的中间层，不属于新的外部输入。

## 默认命名

```text
reviews/{YYYY}/{YYYYMM}/{开始日期}-{结束日期}-{关键词}.md
```

两个日期均使用 `YYYYMMDD`，年月目录按回看范围的结束日期归档。关键词应简短、具体、有材料依据，一般不超过 12 个中英文字符；去掉 `/`、`\` 和换行等不适合文件名的字符。

例如：

```text
reviews/2026/202608/20260817-20260823-产出焦虑.md
```

执行回看的日期记录在文件 frontmatter 的 `date` 中，实际覆盖范围记录在 `period` 中。

## 约定

- 每次 Weekly Review 都保存一份档案，即使没有发现输出或 Practice 方向。
- 回看依据必须指向具体的 Journal 或 Input 路径。
- 后续回答、选择的输出方向和最终成品链接，可以继续追加到同一份回看文件。
- 下一次回看默认只把 `daily/journal/` 与 `daily/inputs/` 当作原始证据，不把旧 Reviews 重复计入。
- 创建新文件前，先查找同一开始与结束日期的 Review；已有 1 份时更新原文件并保留原文件名，已有多份时停止并确认。
