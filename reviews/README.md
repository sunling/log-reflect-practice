# Reviews

这里保存对一段时间 Daily 的回看档案。回看是从原始记录走向问题、表达与 Practice 的中间层，不属于新的外部输入。

## 默认命名

```text
reviews/{YYYY}/{YYYYMM}/{YYYYMMDD}-weekly-review.md
```

文件名日期使用本次回看的执行日期。文件内部记录实际覆盖的开始与结束日期。

## 约定

- 每次 Weekly Review 都保存一份档案，即使没有发现文章或 Practice 方向。
- 回看依据必须指向具体的 Journal 或 Input 路径。
- 后续回答、选择的写作方向和最终文章链接，继续追加到同一份回看文件。
- 下一次回看默认只把 `daily/journal/` 与 `daily/inputs/` 当作原始证据，不把旧 Reviews 重复计入。
- 同一天重复运行时更新原文件，不创建 `v2` 或 `final`。
